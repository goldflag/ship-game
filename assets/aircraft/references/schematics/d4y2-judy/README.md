# Yokosuka D4Y2-C, P. Endsleigh Castle, Aircraft Profile 241 plate (scan p.17)

Source: https://www.gruppofalchi.com/files/Profile-Publications-Aircraft-241---Aichi-D3A-Yokosuka-D4Y.pdf

Creator/provenance: P. Endsleigh Castle ARAeS, Profile Publications Ltd; Aircraft Profile 241.

Variant: D4Y2-C reconnaissance Model 1-2; external airframe used for D4Y2, bomber-bay internals not evidenced.

`source.json` records the original download, retained file, hash and rights. `measured-overlay.png` marks the manually sampled body (blue), fin (orange), canopy (magenta), and plan outline (red/green where on the same plate). The measurement recipe retains raw pixel points; the model JSON converts them to normalized length and meters.

These are published external-shape references, not manufacturing sections. Hidden fuselage cross sections, canopy widths, small fittings, paint and animation travel remain reconstructions. The drawing's availability does not imply a public-domain license. Original imagery is retained under assets only, outside the public game asset path.
