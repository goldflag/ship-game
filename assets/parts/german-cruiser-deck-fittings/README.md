# German cruiser deck fittings

Original capstan, raised deck hatch and unlit fork-mounted searchlight from the
approved local Admiral Hipper recipe. Generic catalog variants were inspected;
their dimensions and silhouettes differ, so these retain the original Hipper
geometry as reusable components. The deck sole is the attachment datum.

No downloaded model supplies geometry. Fresh external-reference verification
remains incomplete. Masses are provisional game values. The hatch is static;
the searchlight has no aiming or illumination simulation. Ship installations
still require attachment and clearance review.
