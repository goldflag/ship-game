# German cruiser mounts

Original geometry for the approved [GameModels3D pgsc108](https://gamemodels3d.com/en/games/worldofwarships/vehicles/pgsc108) A/AB fit. The builder reads only the compiled catalog and original materials/helpers. No source mesh, texture or transform cache is an authoring input.

Distinct 203 mm C/34 gunhouses retain separate rangefinder and plain variants. The 105 mm C/33 C/31 shield is separate from the legacy Bismarck preview. Hipper's 37 mm twins reuse the registered original SK C/30 builder. Light mounts retain their particular shield, feed and case-catching arrangements.

The Admiral Hipper installation has been inspected against the approved A/AB reference, including exposed mechanisms, attachments and combined articulation. Library review metadata remains conservative: a new installation still needs its own reference and clearance review. Export validation checks articulation coordinates, not visual fidelity. Ballistics, armor, stocks and travel limits are provisional game calibration. Source-visible exterior fit is the reference target; this is not a separately certified historical equipment schedule.

The main mount canvas now follows the raked gunhouse face with a fixed seam and
pitching cuff; barrels slide through the cuff during recoil. Rangefinder wings
use an attached faceted enclosure. C/31 shields include the continuous lower
front armor, open upper gun slots, sight housings and closed receiver hood ends.
Tube and handwheel tessellation is reduced, and the Flak 38 catcher retains a
sparse modeled net over its continuous bag. These are independent original
geometry changes; reference geometry remains viewing-only. Standalone review
does not certify neighboring or installed ship clearance.
