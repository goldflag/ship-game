# Convoy reference material

Revision 2 uses the retained [schematics, provenance and reading notes](plans/README.md). The production inputs are independently authored measurements, blueprints and component recipes, not scanned images or another game's mesh.

Retained revision-1 photographic context:

- `liberty-underway-nps.jpg`: NPS Photo 4, Patrick Henry (1941), credited to the Library of Congress. Qualitative early/light-load silhouette; not a late armed configuration.
- `sackville-parks-canada.jpg`: Parks Canada museum exterior (2006). Superseded as Flower configuration evidence; do not mix restored Sackville equipment into Cobalt 1941.
- `victory-excluded-nps.jpg`: NPS Photo 2, USMC photo 4236 (1945). HTML alt text misleadingly says Liberty, but caption identifies Victory. Still excluded from Liberty evidence. The new Victory uses the HAER plan package instead.

No photograph is used as a runtime texture.
